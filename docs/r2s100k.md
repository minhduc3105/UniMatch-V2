# R2S100K pseudo-mask experiment with UniMatch V2

This pipeline trains UniMatch V2 using the 1,366 labeled `val` images and unlabeled `train` images, exports EMA-teacher masks for all 9,562 train images, and evaluates the saved masks against the separate train GT manifest. It does not load `test` data or run validation during training.

The supplied dataset has 1,366 image basenames in common between `train` and `val`. By default, `prepare_r2s100k.py` leaves these images out of the unsupervised training manifest to prevent the same image from entering both labeled and unlabeled branches. It still writes `images_train.jsonl` and `eval_train.jsonl` for all 9,562 train images, so export and evaluation cover the full train set. Use `--include-overlap` only when intentionally accepting the overlap; the training command then needs `--allow-overlap`.

## Prepare the dataset

Run from the repository root. The output directory must be separate from the original dataset.

```bash
python3 prepare_r2s100k.py \
  --data-root /path/to/r2s100k \
  --output-root /path/to/r2s100k_unimatch
```

The script checks the expected 9,562 train and 1,366 val pairs, validates image/mask dimensions and every RGB class color, writes class-ID PNGs under `labels/`, and creates JSONL manifests. If you need to accept train/val overlap:

```bash
python3 prepare_r2s100k.py \
  --data-root /path/to/r2s100k \
  --output-root /path/to/r2s100k_unimatch \
  --include-overlap
```

## Install and fetch DINOv2 weights

Create an environment with CUDA-enabled PyTorch and the repository requirements, then download DINOv2-Small weights:

```bash
python3 -m pip install -r requirements.txt
bash scripts/download_dinov2_small.sh
```

## Smoke run on the 4 GB RTX 3050

This uses 8 labeled and 8 unlabeled examples, crop 140, batch 2, AMP, and two optimizer updates. It writes to a smoke-only directory.

```bash
python3 train_r2s100k.py \
  --data-root /path/to/r2s100k \
  --labels-root /path/to/r2s100k_unimatch \
  --labeled-manifest /path/to/r2s100k_unimatch/manifests/labeled_val.jsonl \
  --unlabeled-manifest /path/to/r2s100k_unimatch/manifests/unlabeled_train.jsonl \
  --pretrained pretrained/dinov2_small.pth \
  --output-root exp/r2s100k/smoke \
  --crop-size 140 --batch-size 2 --num-workers 0 \
  --limit-labeled 8 --limit-unlabeled 8 --max-steps 2
```

The smoke checkpoint can be used to exercise export and metrics on two images; smoke metrics are not the experiment result.

```bash
python3 generate_pseudo_masks_r2s100k.py \
  --data-root /path/to/r2s100k \
  --labels-root /path/to/r2s100k_unimatch \
  --manifest /path/to/r2s100k_unimatch/manifests/images_train.jsonl \
  --gt-manifest /path/to/r2s100k_unimatch/manifests/eval_train.jsonl \
  --checkpoint exp/r2s100k/smoke/final.pth \
  --output-root exp/r2s100k/smoke/predictions \
  --crop-size 140 --stride 92 --inference-batch-size 1 --limit 2 --num-visualizations 2

python3 evaluate_pseudo_masks_r2s100k.py \
  --gt-manifest /path/to/r2s100k_unimatch/manifests/eval_train.jsonl \
  --labels-root /path/to/r2s100k_unimatch \
  --labeled-manifest /path/to/r2s100k_unimatch/manifests/labeled_val.jsonl \
  --prediction-manifest exp/r2s100k/smoke/predictions/predictions.jsonl \
  --prediction-root exp/r2s100k/smoke/predictions \
  --output-root exp/r2s100k/smoke/metrics --limit 2
```

## Full run on a Vast RTX 3090

Transfer the repo, source dataset, prepared output, and `pretrained/dinov2_small.pth` to the Vast instance. Keep the directory layout stable, or update the two roots and manifest arguments. Run one GPU process. The config uses crop 518, batch 2, AMP, 40 epochs, seed 42, DINOv2-Small, AdamW with backbone LR `5e-6` and decoder LR multiplier 40, and confidence threshold 0.95.

```bash
python3 train_r2s100k.py \
  --data-root /workspace/r2s100k \
  --labels-root /workspace/r2s100k_unimatch \
  --labeled-manifest /workspace/r2s100k_unimatch/manifests/labeled_val.jsonl \
  --unlabeled-manifest /workspace/r2s100k_unimatch/manifests/unlabeled_train.jsonl \
  --pretrained pretrained/dinov2_small.pth \
  --output-root exp/r2s100k/full
```

The script does not create a val loader or choose a checkpoint using train GT. It saves `latest.pth` after every epoch, `final.pth` at the end, `train_metrics.csv`, and `run_config.json`. Resume an interrupted run with:

```bash
python3 train_r2s100k.py \
  --data-root /workspace/r2s100k \
  --labels-root /workspace/r2s100k_unimatch \
  --labeled-manifest /workspace/r2s100k_unimatch/manifests/labeled_val.jsonl \
  --unlabeled-manifest /workspace/r2s100k_unimatch/manifests/unlabeled_train.jsonl \
  --pretrained pretrained/dinov2_small.pth \
  --output-root exp/r2s100k/full \
  --resume exp/r2s100k/full/latest.pth
```

If the full crop does not fit in VRAM, use `--crop-size 392` for both training and export and keep the run configuration with its artifacts.

## Export masks and evaluate train GT

Export uses EMA weights by default, pads image edges as needed, averages probabilities over overlapping sliding windows, and restores each mask to the original image dimensions. It writes 8-bit class-ID PNGs to `full/` and masks with pixels below confidence 0.95 set to 255 under `confident/`. The 32 seeded visualizations show image, GT, pseudo mask, and overlay.

```bash
python3 generate_pseudo_masks_r2s100k.py \
  --data-root /workspace/r2s100k \
  --labels-root /workspace/r2s100k_unimatch \
  --manifest /workspace/r2s100k_unimatch/manifests/images_train.jsonl \
  --gt-manifest /workspace/r2s100k_unimatch/manifests/eval_train.jsonl \
  --checkpoint exp/r2s100k/full/final.pth \
  --output-root exp/r2s100k/full/predictions

python3 evaluate_pseudo_masks_r2s100k.py \
  --gt-manifest /workspace/r2s100k_unimatch/manifests/eval_train.jsonl \
  --labels-root /workspace/r2s100k_unimatch \
  --labeled-manifest /workspace/r2s100k_unimatch/manifests/labeled_val.jsonl \
  --prediction-manifest exp/r2s100k/full/predictions/predictions.jsonl \
  --prediction-root exp/r2s100k/full/predictions \
  --output-root exp/r2s100k/full/metrics
```

Reports include dataset-level pixel-weighted mIoU with and without background, per-class IoU/Dice, pixel accuracy, confidence-filtered coverage, and conditional metrics on retained pixels. A class with zero union is `N/A` and does not enter the relevant mean. When `--labeled-manifest` is supplied, reports split results into all train images, the 1,366 images also used as labeled val data, and the clean train-only unlabeled subset. The clean subset provides the least contaminated pseudo-mask quality score; the combined score includes images that had GT during training and is not a held-out generalization score.
